# Kuldeep Singh — 3D Portfolio & Data Analyst Showcase

Modern, high-performance portfolio website built with React, TypeScript, Tailwind CSS, and Three.js.

## 🚀 How to Run Locally

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build production bundle:
```bash
npm run build
```
